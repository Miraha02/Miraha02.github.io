Vesta-Recipe is an application realised in vibe coding. It was meant as a test application that would allow me to get initiated to vibe coding (development assisted by AI) and to local and private use. I decided to plan a deployment on the Play Store as I saw its daily utility. Then I started adding more and more features. Today, it can manage recipes, stocked ingredients and auto-generated shopping list. It is free to use with in-app ads (Vesta-Recipe has not been deployed yet, so only testing ads are integrated). The server is up on Cloudflare Wrokers.
